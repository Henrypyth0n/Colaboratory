<sqlite> Tips

DDL (Data Definition): The blueprint.
CREATE TABLE, DROP TABLE, ALTER TABLE, ADD, DATABASE

DML (Data Manipulation): The intake.
INSERT INTO, UPDATE, SET, DELETE
DQL (Data Querying): The retrieval (90% of your work).
SELECT, FROM, WHERE, ORDER, BY, ASC, DESC, BETWEEN, HAVING, DISTINCT, DELETE, LIMIT, AS, ON, GROUP
KEYS
PRIMARY KEY, FOREIGN KEY, UNIQUE, (REFERENCES used with foreign keys)
Relational Logic: The connections.
JOIN (The glue), INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL JOIN

Advanced

Remove Duplicates:
DELETE FROM table_name WHERE id NOT IN (SELECT MIN(id) FROM table_name GROUP BY column_to_check);
Check for Empty Values:
SELECT * FROM table_name WHERE column_name IS NULL OR column_name = '';
Rename/Modify Columns: ALTER TABLE table_name RENAME COLUMN old_name TO new_name;
Group & Count:
SELECT era, COUNT(*) as total_count FROM music_facts GROUP BY era ORDER BY total_count DESC;
Filter Aggregates:
SELECT era, AVG(difficulty_level) FROM music_facts GROUP BY era HAVING AVG(difficulty_level) > 7;
The "Relational Link":
SELECT m.concept, c.composer FROM music_facts m JOIN composers c ON m.composer_id = c.id;
sql functions (aggregates):
SUM(), AVG(), MIN(), MAX(), COUNT()
Conditionals:
IF, CASE, WHEN, THEN, ELSE, END
ALL, ANY, EXSISTS, IN, AND, NOT,OR, LIKE, IN, IS NULL, IS NOT NULL
